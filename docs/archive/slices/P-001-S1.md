## Objective

Expose the hub moments at the **C++ API** level as read-only methods on `RotorState`:
```cpp
double get_C_Mx() const;
double get_C_My() const;
```
These wrap the C functions from `P-001-S0`. Behavior matches `get_C_T()`/`get_C_Q()`:
return `0.0` when the inner pointer is null (degraded read, non-throwing —
`cppbindings.cpp:757`).

## Why
The C++ layer wraps each `OC_*` pointer in a RAII class storing a `void*`; rotor scalar
getters are one-liners: `double RotorState::get_C_T() const { double o=0; if(ptr_)
oc_rotor_state_get_C_T(rst(*this),&o); return o; }` (`cppbindings.cpp:757`). `rst(*this)`
casts the `void*` down to `const OC_RotorState*`. This slice adds the two hub-moment
one-liners + their declarations in `include/opencopter.hpp` (`class RotorState`, lines 671-697).
