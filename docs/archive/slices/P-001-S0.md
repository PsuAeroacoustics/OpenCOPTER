## Objective

Make the two hub-moment quantities available through the **C API** as read-only getters:
```c
void oc_rotor_state_get_C_Mx(const OC_RotorState* state, double* result_out);
void oc_rotor_state_get_C_My(const OC_RotorState* state, double* result_out);
```
These return the per-rotor hub-moment coefficients already computed by the D core:
`RotorStateT.C_Mx` (roll) and `RotorStateT.C_My` (pitch) in
`source/opencopter/aircraft/state.d:186-187`.

## Why
`C_T`/`C_Q` are exposed today as `oc_rotor_state_get_C_T` (`include/opencopter.h:359`) and
`oc_rotor_state_get_C_Q` (`:361`), implemented in `source/opencopter/cbindings.d:589-604`.
The hub moments `C_Mx`/`C_My` are computed in the same struct (`bladeelement.d:472-473`) but
missing from the C surface. This slice adds them, mirroring the `C_T`/`C_Q` pattern. The C
"implementation" is an `extern(C)` function in a **D** module — `cbindings.d` *is* the C ABI.

### 2. `source/opencopter/cbindings.d` — implement the two functions
Anchor: after the `oc_rotor_state_set_C_Q` block (before `oc_aircraft_state_get_rotor_C_T` at line 606).
```d
extern(C) void oc_rotor_state_get_C_Mx(const OC_RotorState* state, double* result_out) {
    auto s = cast(const(RotorState)*)state;
    if (s !is null && result_out !is null) *result_out = (*s).C_Mx;
}
extern(C) void oc_rotor_state_get_C_My(const OC_RotorState* state, double* result_out) {
    auto s = cast(const(RotorState)*)state;
    if (s !is null && result_out !is null) *result_out = (*s).C_My;
}
```
Notes: same cast/guard shape as neighbors; preserve the null-guard (ABI contract); do **not**
add setters or aircraft-indexed variants (out of scope per P-001 §3).
