## Objective

Add test coverage proving the new getters behave correctly at **both** API levels, and run the
suite for regressions:
- **C level** — `tests/src/test_api_aircraftstate.cpp`: `AircraftState.HubMomentGettersValueAndNullSafe`
- **C++ level** — `tests/src/test_cpp_api.cpp`: `CPP_RotorState.HubMomentNullSafe` (+ optional stretch)

## Why
`C_Mx`/`C_My` are **computed outputs** with **no setter**, so (unlike the `C_T`/`C_Q` round-trip
at `test_api_aircraftstate.cpp:174-182`) we can't inject a known non-zero value. The C test must
(a) prove the getters WRITE to the out-pointer by seeding `1e9` and asserting it's overwritten to a
finite value (defeats "write-never-happened", which `EXPECT_DOUBLE_EQ(0.0)` alone can't catch), and
(b) assert `0.0` (D POD default pre-step) and null-safety. The C++ test's cheap case is a **null
wrapper** (`default RotorState rs;` → `get_C_Mx()==0`), mirroring `CPP_Aircraft.NumRotorsNull`
(`test_cpp_api.cpp:36-40`). A positive C++ case needs a fully-constructed `AircraftState`
(`opencopter.hpp:790-800`) — mark as `GTEST_SKIP` if not readily assembleable in that TU.

Anchor: a new `TEST(...)` in the `AircraftState` suite after `AircraftState.RotorStateCTSetGet`
(~line 201), before `AircraftState.BladeStateDCM` (line 206). Reuse the **exact setup/teardown** of

```cpp
TEST(AircraftState, HubMomentGettersValueAndNullSafe) {
    OC_Aircraft* ac = /* ... same as RotorStateCTSetGet ... */;
    OC_RotorGeometry* rotor = /* ... same ... */;
    OC_Inflow* inflow = /* ... same ... */;
    OC_AircraftInputState* ac_input = /* ... same ... */;
    OC_AircraftState* state = oc_aircraft_state_create(/* ... same args ... */);
    ASSERT_NE(state, nullptr);

    OC_RotorState* rs = oc_aircraft_state_get_rotor_state(state, 0);
    ASSERT_NE(rs, nullptr);

    double cmx = 1.0e9, cmy = 1.0e9;         // (a) prove the write path
    oc_rotor_state_get_C_Mx(rs, &cmx);
    oc_rotor_state_get_C_My(rs, &cmy);
    EXPECT_NE(cmx, 1.0e9);
    EXPECT_NE(cmy, 1.0e9);
    EXPECT_TRUE(std::isfinite(cmx));
    EXPECT_TRUE(std::isfinite(cmy));

    EXPECT_DOUBLE_EQ(cmx, 0.0);              // (b) pre-step POD default
    EXPECT_DOUBLE_EQ(cmy, 0.0);

    double dummy = 1.0e9;                    // (c) null-safety (mirrors line 27)
    oc_rotor_state_get_C_Mx(nullptr, &dummy);
    oc_rotor_state_get_C_Mx(nullptr, nullptr);
    oc_rotor_state_get_C_My(nullptr, &dummy);
    oc_rotor_state_get_C_My(nullptr, nullptr);

    oc_aircraft_state_destroy(state);        // (teardown: same as RotorStateCTSetGet)
    oc_inflow_destroy(inflow);
    oc_aircraft_input_state_destroy(ac_input);
    oc_rotor_geometry_destroy(rotor);
    oc_aircraft_destroy(ac);
}
```
